项目名称：数字收藏馆 (FavGallery)
项目定位： 一款浏览器辅助工具，帮助用户整理和管理自己在社交平台上的个人互动记录（关注、点赞、收藏等）。通过本地化存储，让用户能够离线浏览和检索自己的社交足迹。
核心功能：
📚 个人记录整理：自动归类用户在平台上的关注列表、点赞内容、收藏夹
💾 本地备份：将元数据保存到用户指定的本地文件夹，支持离线查看
🔍 智能检索：提供搜索、筛选、排序功能，快速找到所需内容
🌐 多平台支持：兼容主流社交平台（抖音、小红书等）
技术特点：
纯前端实现，无需服务器
使用浏览器原生 API（File System Access API、IndexedDB）
增量更新机制，避免重复操作
尊重平台速率限制，内置防频控保护
免责声明： 本工具仅用于帮助用户管理自己账号的个人数据，不涉及任何第三方数据的获取或传播。用户需遵守各平台的使用条款，合理使用本工具。本工具不提供任何破解、绕过平台限制的功能。
适用场景：
✅ 个人数据归档和备份
✅ 离线浏览自己的收藏内容
✅ 整理和管理社交互动记录
❌ 批量获取他人数据
❌ 商业用途的数据采集
❌ 违反平台规定的自动化操作
 
English Version
Project Name: FavGallery
Project Description: A browser extension that helps users organize and manage their personal interaction records (follows, likes, favorites, etc.) on social media platforms. Through local storage, users can browse and search their social footprints offline.
Core Features:
📚 Personal Record Organization: Automatically categorize users' follow lists, liked content, and favorites
💾 Local Backup: Save metadata to user-specified local folders for offline viewing
🔍 Smart Search: Provide search, filter, and sort functions to quickly find content
🌐 Multi-Platform Support: Compatible with mainstream social platforms (Douyin, Xiaohongshu, etc.)
Technical Highlights:
Pure frontend implementation, no server required
Uses native browser APIs (File System Access API, IndexedDB)
Incremental update mechanism to avoid redundant operations
Respects platform rate limits with built-in anti-throttling protection
Disclaimer: This tool is designed solely to help users manage their own account's personal data. It does not involve acquiring or distributing third-party data. Users must comply with each platform's Terms of Service when using this tool. This tool does not provide any functionality to bypass platform restrictions or circumvent security measures.
Use Cases:
✅ Personal data archiving and backup
✅ Offline browsing of your own saved content
✅ Organizing and managing social interaction records
❌ Bulk acquisition of others' data
❌ Commercial data scraping
❌ Automated operations violating platform policies
