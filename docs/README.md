# FavGallery - 跨平台社交内容备份管理工具

## 📖 项目简介

FavGallery 是一个 Chrome 扩展程序，帮助用户管理和备份个人在社交平台（抖音、小红书等）上的收藏内容，防止数据丢失。

## ✨ 核心功能

- ✅ **多平台支持** - 抖音已实现，其他平台可扩展
- ✅ **关注列表管理** - 同步和管理关注的作者
- ✅ **点赞作品管理** - 备份点赞的视频和图集
- ✅ **收藏夹管理** - 管理多个收藏夹
- ✅ **作品下载** - 下载视频、图集、封面到本地
- ✅ **智能备份** - 按季度分片存储，增量检测避免重复
- ✅ **数据恢复** - 从备份文件恢复到数据库

## 🚀 快速开始

### 安装扩展

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 启用"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 FavGallery 项目根目录

### 使用步骤

1. 访问抖音网页版并登录
2. 点击扩展图标打开侧边栏
3. 选择保存文件夹
4. 点击"加载点赞列表"或"加载关注列表"
5. 等待数据同步完成

## 🛠️ 技术栈

- **Chrome Extension Manifest V3** - Service Worker 架构
- **IndexedDB** - 本地数据库存储
- **File System Access API** - 文件系统操作
- **ES6 Modules** - 模块化开发
